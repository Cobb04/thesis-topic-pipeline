# 精修：把题目压成最小可行设计

## 一、一句话重写

按论文类型选句式。写不出这一句，说明题还没想清。

| 类型 | 句式 |
|---|---|
| 因果实证 | X 是否通过机制 Z 影响 Y，在场景 P 下，利用变异 V？ |
| **测量 / 事实** | 对象在哪些维度上、以什么口径被披露，呈什么形态，与什么对照？ |
| 理论 | 什么条件下会出现什么悖论/非单调结果？ |
| 政策报告 | 制度落地的实际形态与偏差在哪？ |

测量型的陷阱是写成"X 是否影响 Y"，那会把题推向自己做不了的因果。

## 二、竞争性假设（防表扬稿，必做）

所有"问题及对策"型论文都有同一个死法：写成企业表扬稿。解法是先立一个对立假设，让数据裁决。

模板：

- 假设 A：披露质量**实质改善**
- 假设 B：只是**篇幅扩张**
- 判据：质量评分线与篇幅指标线同向上升 → A；只有篇幅上升 → B

篇幅要可量化，选最省事的一种：**页数 / 字数 / 图表数 / 议题条目数**。至少取两个，避免单一指标被质疑。

## 三、维度设计

规则：

- **3—5 个维度**，不要七个。维度一多就变成机械打分，反而没有结论。
- 每个维度必须有**可验证的观测点**和**明确的数据来源**，不能是"披露是否充分"这种没法判的表述。
- 优先选能相互张开的维度（一个测广度、一个测深度、一个测可靠性、一个测与财务的关联）。

一个经过验证的四维框架（ESG 披露类）：

| 维度 | 观测点 | 数据来源 |
|---|---|---|
| 范围覆盖 | 指引议题的逐项对应位置 | 报告目录 + 议题索引 |
| 量化连续性 | 关键指标是否有值、口径是否变 | 关键绩效表 |
| 可靠性 | 是否第三方鉴证、依据标准、覆盖范围 | 鉴证声明页 |
| 财务勾稽 | 披露金额能否在报表找到同量级科目 | 年报附注 |

## 四、财务勾稽怎么落地（会计专业的差异化所在）

这是"问题及对策"模板里最能体现专业、也最少被前作做的部分。常见落点：

| 披露项 | 报表落点 |
|---|---|
| 环保/节能投入 | 在建工程、管理费用—环保费 |
| 政府补助（环保专项） | 其他收益 / 递延收益 |
| 环境恢复治理义务 | 预计负债 |
| 碳排放权配额 | 无形资产 / 交易性金融资产（视持有目的） |
| 研发投入（绿色技术） | 研发费用、开发支出 |

要点：**口径一定对不上**。报告说"节能低碳投资 32 亿"，报表里不会有同名科目。你的工作是把口径差异说清楚，而不是硬凑相等。

## 五、定题说明（写给导师看的那一段）

模板：

> 已有研究对该公司的关注集中在〔三类角度〕：〔A〕、〔B〕、〔C〕。上述研究的样本期均截至〔年份〕，**未能覆盖〔你的增量：新年份 / 新准则 / 新政策〕**。本文以〔样本〕为对象，以〔标尺〕为准，重点考察〔增量部分〕，这是既有研究在〔维度〕上未触及的。

作用不是客套，是**在定题当场就把答辩风险消解掉**。写完检查一遍：里面有没有具体年份和篇数？没有就是空话。

## 六、定题前的可行性抽查

定题之前先做 3—5 项能在一周内完成的抽查。合格的选题应该能被这些抽查推翻——推不翻才说明它站得住。

ESG 披露类通用清单：

1. 下载最早一年与最新一年两份报告，确认关键指标**是否都有值**；没有的话，量化连续性的起点要后移。
2. 查最新一份报告**有没有第三方鉴证声明**；没有的话，"可靠性"这一维可能整列都是 0，失去区分度。
3. 查年报**是否单列**你打算勾稽的科目；没有单列就得换科目或换说法。
4. 把指引议题与报告章节做成**映射表**，看有多少议题根本找不到对应内容。
5. **只试评最早和最新两年**。两年都拉不开分，立刻换题——不要等症状在三个月后出现。

第 5 项是最重要的一条。它花两小时，能在定题阶段就否决一个看起来很好的题。
